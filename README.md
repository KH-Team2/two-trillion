## 📌 프로젝트 소개

"쉽게 알아보는 연말정산 시뮬레이터"

연말정산 쉽게 이해하기 도우미
현재 상황에 따른 연말정산 예상 결과를 제공한다.
적용되었거나 추가 적용 가능한 혜택 정보를 제공한다.

절세 시뮬레이션 제공
상황 변동 시의 연말정산 예상 결과와 결과별 대시보드를 제공한다.
비슷한 그룹 내의 결과 통계를 제공한다.

## 🌿 Git Branch

- `main` : 최종 버전
- `develop` : 기능 통합 및 테스트
- 작업 브랜치 : 개인 기능 개발

### 개발 흐름

작업 브랜치 → Pull Request → develop(테스트 및 통합) → Pull Request → main

## 📌 Git 규칙

- `main`, `develop` 브랜치에 직접 Push하지 않습니다.
- 기능 개발은 별도의 작업 브랜치에서 진행합니다.
- Pull Request를 통해 코드를 병합합니다.
- PR은 main은 2명 이상, develop은 1명 이상의 승인을 받은 후 Merge합니다.
- Force Push를 금지합니다.
- `.env`, API Key, DB 비밀번호 등 민감정보는 GitHub에 업로드하지 않도록 주의합니다.
