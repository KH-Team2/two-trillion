```GitHub 저장소
     ↓ clone
내 컴퓨터

코드 수정
  ↓
add
  ↓
commit
  ↓
push
  ↓
GitHub에서 PR
  ↓
develop에 merge

git clone https://github.com/KH-Team2/two-trillion.git
: GitHub에 있는 two-trillion 저장소를 내 컴퓨터에 처음으로 통째로 받아오는 명령어

git switch develop
: 현재 작업할 브랜치를 develop으로 변경
git switch -c feature/chatbot
: 현재 develop을 기준으로 새로운 feature/chatbot 브랜치를 만들고, 동시에 그 브랜치로 이동
-c가 **새 브랜치 생성(Create)**이라는 의미

git branch : 현재 브랜치 확인
git status : 현재 Git 상태를 확인
git fetch origin : GitHub의 최신 상태를 확인할 수 있도록 가져오지만 내 코드에는 바로 합치지 않아

git pull origin develop
: GitHub의 최신 develop 내용을 내 컴퓨터의 develop에 가져오는 것
"다른 팀원들이 develop에 합쳐놓은 최신 코드 내 컴퓨터에도 적용해줘."
git pull : 다른 사람이 수정한 최신 코드를 받아올 때

git push -u origin feature/chatbot
: 내 컴퓨터에서 만든 feature/chatbot을 GitHub에도 처음 등록한 것
-u는 앞으로 이 로컬 브랜치와 GitHub 브랜치를 연결해두라는 뜻
다음부터는 git push

git add .
:  현재 변경한 파일들을 다음 Commit에 포함시키겠다고 등록
.은 현재 폴더 이하의 변경사항을 전부 의미

git commit -m "챗봇 API 구현"
: add한 변경사항을 하나의 작업 기록으로 저장

git push
: Commit한 내용을 GitHub에 올린다.

git merge
: 먼저 네 작업을 Commit -> git fetch origin -> git merge origin/develop

git log --oneline
: Commit 기록 확인```
