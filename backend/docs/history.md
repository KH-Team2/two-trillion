## 2026-11-13

- 그룹 비교 통계 조회 API 추가 (`GET /api/group-stats/{taxYear}` · F-06-02 · 대시보드 「나와 비슷한 사람들은」): 본인의 성별·연령대 그룹과 총급여 구간 그룹의 국세통계 평균(인원 · 1인당 총급여 · 결정세액 · 환급세액)을 돌려줌. 못 찾은 그룹(성별 미입력 · 그 연도 소득 없음)은 그 칸만 null이고 오류가 아님(200). 새 패키지 `statistics` (`GROUP_STAT` 읽기만).
  - SQL 규칙: 통계 연도는 귀속 연도 이하에서 가장 최근(국세통계는 2년쯤 늦게 나와서 지금은 2024) · 나이 = 귀속 연도 − 태어난 해 · 성별·연령대는 MEMBER, 급여 구간은 INCOME을 이어서 회원 번호만으로 찾음 · `AGE_MIN` · `AGE_MAX`가 NULL이면 제한 없음(20대 이하 · 70대 이상) · 급여는 `SALARY_MIN` 초과 ~ `SALARY_MAX` 이하이고 `SALARY_MIN`에는 「NULL이면 통과」를 붙이지 않음 (둘 다 NULL인 「1억 초과(결정세액 없는 자)」 행이 누구에게나 걸리는 것을 막으려고).
  - 확인: 학원 DB에서 회원 81 → 여성 40대 · 4천만 이하, 82 → 여성 50대 · 2천만 이하, 없는 회원 → 200에 둘 다 null. 테스트 6개 추가 (Service 3 · Controller 3).
  - 화면에 있던 통계 스냅샷(`frontend/src/data/statistics/group-stat-2024.json`)과 평균이 조금 다름: 세액 합계는 같고 나누는 인원 칸이 다름. DB는 국세청 원본의 「과세대상근로소득(총급여)」 인원(인원과 금액을 같은 칸에서 · 서비스의 총급여 정의와 같음), 스냅샷은 「급여총계」 인원(비과세 소득만 있는 사람 포함). 예: 여성 40대 1인당 결정세액 2,274,940(DB) 대 2,274,651(스냅샷) · 30세 미만은 1 ~ 2% 차이. DB는 고칠 것 없음.
